Settings

Everything is stored in this browser. Only the AI tools talk to the network — to openrouter.ai, with your key.

Appearance

Follow the system, or force a theme.

Live scan

Scan every page you open for hidden text and count what it finds on the toolbar icon — a warning before you paste a page into an AI tool or let an agent read it. Off by default, because it needs permission to read all sites. Pages are analysed locally; nothing is sent anywhere.

Sites
The popup’s Scan tab can add or remove the current site too.

Paste guard

Hold a paste into an AI chat when the text hides something — invisible Unicode tags, emoji steganography, zero-width runs, bidi overrides, invisible letters or look-alike letters — and choose: paste it cleaned, paste it as is, or cancel. Pastes without such characters go through untouched. Needs permission for the sites below; the check runs locally.

Sites

AI tools (OpenRouter)

PromptCraft, Anti-Classifier, translation and alphabet generation use your own OpenRouter API key. It never leaves this browser except in requests to openrouter.ai.

Translation always uses 0.3.

ML second opinion

This build carries ONNX Runtime, so a prompt-injection classifier can score what the scanner finds — next to its severity, never instead of it. The model is downloaded once from Hugging Face when you ask (ProtectAI deberta-v3-base-prompt-injection-v2, Apache-2.0, 747 MB; the exact revision, size and SHA-256 are checked before it is kept) and stays in this browser.

Emoji steganography

How “Emoji · bits” encodes: one variation selector per bit after the carrier. Change these only to match another tool — the decoder uses the same settings.
